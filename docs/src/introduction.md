# Introduction

SlopWorld turns RimWorld's colony interface into a workspace for coding agents.
Each agent appears as a colonist; select one to open its terminal and enter text.

The game mod presents the interface, while the daemon runs and manages agent
sessions. The daemon is the source of truth for sessions; the mod keeps a local
view for the interface.

Start with [Install](install.md), then explore the [Interface](tour/interface.md),
[Agents and projects](tour/agents-and-projects.md), and [Sandboxing](tour/sandboxing.md) tours.
