## RimWorld

## What builds are supported?

You need a fresh 1.6 native Linux build of RimWorld. You can buy it from GOG (tested by dev) or from any other store.

## Can I play normal RimWorld after installing SlopWorld?

You can and you should!

We make sure to not mess with regular RimWorld installation:

- SlopWorld uses a separate directory for saves and settings (defaults to X)
- SlopWorld can only be run with launcher. If you try to enable mod in regular game, it will refuse to run.

But anyway, better backup your saves before using SlopWorld.

## Do I need to buy DLCs, extension packs?

For SlopWorld: no, only use the core game assets. But if you play RimWorld, the game, I highly recommend to try DLCs, especially Rolalty.
