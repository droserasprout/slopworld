# Attribution

Before using a library or asset, check that its license is compatible with
SlopWorld's use and distribution. Keep the full license text in `licenses/`.
List direct runtime dependencies and bundled assets on `AboutPage`; transitive
dependencies belong in the license notices, not the About credits. Direct
dependencies include the daemon, sidecar, and mod manifests.

These attribution requirements apply to client and daemon dependencies and bundled
assets. Development-only tooling does not need vendored license texts or About credits.
