Comparison with the latest [targeted review](misc-perf-cpu-review-20260914.md),
September 14's Fixed column: 200-row plain ingest rose from 6.275 to 21.878 µs
(+249%), 200-row URL ingest from 40.820 to 58.465 µs (+43%), and the 32-frame
batch from 1289.227 to 4425.271 µs (+243%). That batch now allocates 2,512,728
B/op versus 91,576 B/op (27.4 times as much). The earlier review used one run
per column; this snapshot averages three runs.

Against the latest [full suite](perf-suite-20260911-194111.md), cold ANSI parsing
is 34% faster and 200-row URL ingest is 79% faster, but JSON parsing is 158%
slower and unchanged-screen processing is 874% slower, now allocating 4,920
B/op instead of zero. Commit `a504d93a` replaced the custom JSON plumbing with
Json.NET after those reports; it is a candidate explanation, not an isolated
causal measurement. These helper benchmarks do not measure live game latency.

Daemon no-output p50 varied from 1.98 to 1.97 to 0.88 µs across these runs;
small daemon timing comparisons should account for that variation. Full-redraw
p50 averaged 143.450 µs versus 99.153 µs in the September 11 suite (+45%).
